# StavbaPro — сайт візитка (демо)

Односторінковий сайт для набору працівників на будівництво в Чехії.

## Структура

```
index.html        — розмітка сторінки
css/reset.css     — обнуляючі стилі (reset)
css/style.css     — основні стилі, БЕМ, адаптив (mobile-first)
js/main.js        — меню, анімації при скролі, форма
img/              — сюди кладемо фото клієнта
```

## Методологія

- **БЕМ**: `блок`, `блок__елемент`, `блок--модифікатор` (напр. `vacancy__title`, `button--primary`).
  Стани, які вмикає JS: `is-visible`, `is-locked`, `nav--open`, `burger--active`.
- **Адаптив**: mobile-first, точки перелому 576 / 768 / 992 / 1200 px.
- Кольори, шрифти й радіуси задані змінними в `:root` у `style.css`.
  Головний колір: `--c-accent`.

## Продуктивність

Нескінченні анімації (кран, біжучий рядок, пульсація кнопки) рухаються лише через
`transform` і `opacity` на окремих шарах, тому браузер не перемальовує сторінку щокадру.
Коли блок з анімацією поза екраном, анімація ставиться на паузу (клас `is-paused`).

## Що замінити перед запуском

Пошук по `[` в `index.html` знайде всі заглушки:
`[ВАШ НОМЕР]`, `[СТАВКА]`, `[МІСТО]`, `[МІСТА]`, `[ВАШ_НІК]`, `[ВАШ EMAIL]`,
`[АДРЕСА ОФІСУ]`, `[ГОДИНИ РОБОТИ]`, `[УМОВИ ВИПЛАТ…]`, `[НОМЕР ЛІЦЕНЗІЇ]`.
Також телефон у посиланнях `tel:+420000000000`, `viber://…`, `https://t.me/`.

Назва StavbaPro тимчасова: замінити в `<title>`, логотипі та футері.

## Фото

- Галерея: у `index.html` у кожному `.gallery__item` замінити заглушку на
  `<img class="gallery__img" src="img/photo-1.jpg" alt="..." loading="lazy">`.
- Перший екран: всередину `.hero__media` додати
  `<img class="hero__photo" src="img/hero.jpg" alt="...">` (замість SVG-анімації або поруч).

## Форма

Зараз форма демонстраційна: показує «Дякуємо», але нікуди не відправляє.
Для роботи потрібно вказати сервіс (Formspree, Telegram-бот, PHP-скрипт хостингу)
у `js/main.js`, розділ 5.
